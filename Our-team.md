# Команда Parts Unlimited

## О проекте

Parts Unlimited — учебный проект для изучения программной инженерии и организации командной разработки.

## Команда разработки

В проекте участвуют студенты, выполняющие лабораторные работы по программной инженерии.

## Основные роли

- Руководитель проекта — планирование и координация работ
- Разработчик — реализация функциональности
- Тестировщик — проверка качества программного обеспечения

## Инструменты

- GitHub — совместная разработка
- Git — контроль версий
- GitHub Projects — управление задачами
- GitHub Wiki — документация
- GitHub Actions — автоматизация CI/CD

## Цель командной работы

Научиться распределять задачи, управлять изменениями и организовывать процесс разработки программного обеспечения.
